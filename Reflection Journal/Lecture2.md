# Lecture 2: Version Control Protocols, Graphical Frameworks, and Core Graphics Principles

**Date:** 6 August 2026  
**Course:** CSC360 — Computer Graphics and Interaction

---

The second lecture provided a broad, integrated exploration of both technical infrastructure and core computer graphics fundamentals. We began by analyzing version control accessibility, specifically comparing SSH and HTTPS protocols for Git repository management. Understanding public and private key cryptography through `ssh-keygen` made the security mechanics clear: public keys act as lockboxes shared with remote hosts like GitHub, while private keys remain securely stored in the default home directory (`~/.ssh` on Mac and Linux, or `C:\Users\Username\.ssh` on Windows). We clarified key system concepts, distinguishing SSH as a secure network protocol from a key shell interface, and examined shell environments across operating systems such as `bash` and `zsh` in Linux/Mac alongside Command Prompt and PowerShell in Windows.

Transitioning to graphics architecture, we expanded on the distinction between computer graphics and image processing, highlighting unique edge cases such as generated synthetic imagery—where a visual is an image created algorithmically rather than a captured photograph—and monochrome single-value channels forming black-and-white images. The lecture revisited geometric primitives as the foundational units for drawing, contrasting raster graphics (pixel-array representations dependent on resolution) with vector graphics (mathematically defined shapes scaling seamlessly). Defining a pixel as the smallest addressable physical element on a display device set the stage for exploring basic affine transformations. We analyzed how matrix operations like translation, scaling, and zooming manipulate coordinate spaces to alter rendered elements dynamically.

On the software development side, we explored Java's graphical frameworks via official documentation and constructed a basic Java program capable of rendering simple primitive shapes like lines. We examined the underlying design patterns governing user interface interactivity, focusing on the Observer and Event-Driven patterns where event sources emit triggers and event listeners handle inputs. This brought into focus the core difference between static graphics and interactive graphics, where user actions force frame updates through the repainting process—redrawing UI components when states change or windows resize. Finally, we re-connected continuous curves to differential calculus, establishing how mathematical derivatives define smooth pathways and tangents across digital canvases.
