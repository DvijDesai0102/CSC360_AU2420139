# Lecture 1: Fundamentals of Computer Graphics, Frameworks, and Mathematical Foundations

**Date:** 4 August 2026  
**Course:** CSC360 — Computer Graphics and Interaction

---

The introductory lecture provided a foundational framing of computer graphics as a distinct discipline within computer science. A primary focus was establishing the explicit boundary between traditional graphics, computer graphics, and image processing. While traditional graphics rely on static visual media, computer graphics centers on the algorithmic synthesis of visual content from abstract data structures and mathematical models. Conversely, image processing takes an existing image as input and applies transformations or feature extraction to yield a modified visual or analytical output. Understanding how these two domains interact—such as using image processing techniques for post-processing shaders in a computer graphics pipeline—clarified how visual rendering systems operate end-to-end, underscoring the real-world necessity of graphics across user interfaces, simulations, and interactive media.

Beyond theoretical definitions, the session covered the structural building blocks of graphical rendering, starting with basic geometric primitives like points, lines, angles, curves, and standard shapes. The lecture bridged these theoretical shapes with practical implementation frameworks in the Java ecosystem, comparing legacy toolkits like Java Swing with modern frameworks like JavaFX and the underlying Java Runtime Environment (JRE). Evaluating these framework architectures demonstrated how high-level programmatic interfaces manage state, event handling, and rendering loops to translate raw coordinate data into interactive on-screen graphics components.

A major highlight of the class was the direct application of core mathematical principles to visual representation. We examined the transition from basic linear equations—used to plot straight vector lines—to continuous non-linear representations for curves. Calculus plays an indispensable role in this pipeline: differential calculus is essential for determining local tangents, normals, and velocity vectors along a curve, whereas integral calculus provides the mathematical framework for computing continuous surface areas, volumes, and bounding regions. Connecting differential and integral calculus to discrete pixel displays highlighted the fundamental challenge of computer graphics: translating precise, continuous mathematical formulas into finite raster grids. Moving forward, the key area for revision will be exploring how JavaFX handles vector-to-raster conversion algorithms under the hood and practicing numerical integration techniques for rendering complex curve geometries.
